# مُدَبِّر — إدارة الحلقات القرآنية

تطبيقٌ عربيّ (RTL) لإدارة حلقات تحفيظ القرآن: بطاقات الطلاب، التسميع، الحضور،
الخطّة الأسبوعيّة والشهريّة التكيّفيّة، المصحف الكامل، والنسخ الاحتياطيّ.
يعمل **بلا إنترنت** ببياناتٍ محليّةٍ كاملة على الجهاز (IndexedDB).

## المزايا

| الميزة | الوصف |
|---|---|
| **بطاقات الطلاب** | لكل طالبٍ بطاقةٌ فيها مقداره اليوميّ، شارات التسميع، وحبّات الحضور الأربع (حاضر · متأخر · مستأذن · غائب) |
| **التسميع** | ورقةُ تسميعٍ تعرض مقطع اليوم من **محرّك تدرّجٍ تكيّفيّ**، مع تسجيل المقطع الفعليّ الذي سُمِع |
| **الحضور** | صفٌّ واحد لكل طالبٍ في اليوم بقيدٍ فريد في قاعدة البيانات (`&[studentId+date]`)، وحساب العدّاد من حاضر+متأخر |
| **خطّة الطالب** | صفحةٌ كاملة (أسبوعيّة/شهريّة) بمقاطع سورة/آية حقيقيّة: **حفظ الربط التراكميّ** (٣ أيام)، **تأسيس جزء عمّ** (من الناس إلى الفجر، والمراجعة موقوفةٌ فيها)، وأيام الحضور |
| **محرّك التدرّج** | الموضع يتقدّم **بما سُمِع فعلاً** لا بالمخطَّط، والمراجعة تدور داخل نطاق المحفوظ |
| **المصحف الكامل** | ٦٠٤ صفحاتٍ بخطٍّ قرآنيّ، تنقّلٌ بالسحب، وفيها قارئٌ مستقلّ وعرضٌ داخل الحلقة |
| **النسخ الاحتياطيّ** | تصدير القاعدة كاملةً إلى ملفّ JSON واستعادتها منه (عبر `dexie-export-import`) |
| **التقارير** | تصدير Excel/CSV وورقة A4 للطباعة (PDF) بتخطيطٍ واحد، ورسائل تقريرٍ للمعلّم |
| **يعمل بلا شبكة** | PWA بتخزينٍ مسبق للكود وبيانات المصحف والخطوط، مع تحديثٍ تلقائيّ |

## التقنية

- **React 19** + **TypeScript** + **Vite**
- **Tailwind CSS v4** (تصميمٌ زجاجيّ دافئ، فاتح/داكن)
- **Dexie** (IndexedDB) قاعدةُ بياناتٍ محليّة، مع `dexie-export-import` للنسخ الاحتياطيّ
- **vite-plugin-pwa** للعمل بلا شبكة + `fflate` لبناء ملفّات xlsx
- **الخطوط**: «ثمانية» (Thmanyah) لواجهة التطبيق، وخطٌّ قرآنيّ لنصّ المصحف

## التشغيل

```bash
npm install
npm run dev            # خادم التطوير
npm run build          # بناء الإنتاج
npm run preview        # معاينة نسخة الإنتاج (PWA على المنفذ 4173)
npm run serve          # معاينة على المنفذ 3000 (نفس أصل بياناتك)
npm run lint           # ESLint
```

## بنية المشروع

```
src/
  components/   الواجهات (اللوحة، الطالب، التسميع، المصحف، الخطّة، النسخ الاحتياطيّ…)
  db/           قاعدة Dexie: المخطّط، الاستعلامات، النسخ الاحتياطيّ
  utils/        المحرّكات: التدرّج، الخطّة اليوميّة، الإسقاط الأسبوعيّ/الشهريّ، التصدير
public/
  data/         بيانات المصحف (٦٠٤ صفحات)
  fonts/        خطّ «ثمانية» وخطّ النصّ القرآنيّ
  icons/        أيقونات التطبيق (PWA)
```

## البيانات والخصوصيّة

كل البيانات (الحلقات · الطلاب · الجلسات · الحضور) تُخزَّن **على جهاز المعلّم
وحده** في IndexedDB — لا خادمَ ولا حسابَ ولا إرسالَ لأيّ بيانات. ويمكن أخذ
نسخةٍ احتياطيّة من داخل التطبيق في أيّ وقت.
